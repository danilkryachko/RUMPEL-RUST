# ADR 006: Rumpel Prelude для ИИ-Агентов

## Контекст
Проект разбит на множество крейтов (Cargo Workspaces). При добавлении нового функционала агентам приходилось вручную прописывать длинные цепочки импортов (`use rumpel_world::chunk::Chunk` и т.д.). Это приводило к опечаткам, так как ИИ мог перепутать, в каком именно крейте находится тип.

## Решение
Внедрен паттерн **Prelude**.
Создан крейт `crates/rumpel_prelude`, который реэкспортирует основные типы из базовых библиотек (`rumpel_coords`, `rumpel_blocks`, `rumpel_world`).

## Последствия
- Теперь во всех рабочих крейтах (клиент, рендер, инвентарь) достаточно прописать `use rumpel_prelude::*`.
- Это радикально снижает вероятность галлюцинаций ИИ при импортах и ускоряет разработку.
- В "Конституцию ИИ" добавлено жесткое требование использовать этот импорт.
